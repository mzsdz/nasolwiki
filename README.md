# 나솔위키 매거진

〈나는 SOLO〉에서 떠올린 질문을 독립적인 연애·관계 기사로 읽는 모바일 매거진. 기존 HTML/CSS/JS MVP를 유지합니다.

- 저장소: https://github.com/mzsdz/nasolwiki
- 기존 Vercel 프로젝트: `prj_1wuYQBMCOQ9qsh0dH5Lw0pzGDkGM` / `mzsdz/nasolwiki`
- 배포 주소: https://nasol-wiki.vercel.app
- 기존 위키 도메인 `nasol.wiki`는 변경하지 않았습니다.

## 개발·배포

Node 24, 기본 빌드에 외부 의존성이 없습니다.

```sh
npm run build
npm test
npm run dev
```

`articles.js`는 기존 원고 12편, `app.js`는 공통 화면과 클라이언트 탐색, `scripts/build.cjs`는 같은 화면 함수를 이용해 본문이 들어 있는 HTML 19개를 생성합니다. Vercel은 `dist/`와 `api/events.js`를 배포합니다. 기존 Git 연결의 main 브랜치를 그대로 사용합니다.

기사 고유 URL은 `/article/{id}`입니다. 이전 `/#/article/{id}` 링크도 브라우저에서 새 주소로 전환합니다. 직접 접속·새로고침은 정적 HTML을 반환하고, 없는 주소는 404를 반환합니다. `/saved`는 noindex입니다. 검색엔진 등록이나 검색 노출 자체를 보장하지 않습니다.

## OG와 카카오톡

기본 `og.png`와 기사별 `og/{id}.png`는 1200×630 PNG입니다. 빌드 결과의 HTML에 기사별 제목·설명·절대 이미지 URL·canonical·Article JSON-LD를 넣습니다. 소셜 크롤러는 JavaScript 실행 없이 이를 읽을 수 있습니다. 원고 제목 변경 시 `sharp`와 Noto Sans KR 한글 폰트가 있는 저작 환경에서 `node scripts/generate-og.cjs`로 PNG를 갱신해 함께 커밋합니다.

배포 후 KakaoTalk 사용자 에이전트로 기사 HTML과 PNG의 공개 접근을 확인합니다. 실제 카카오톡 대화방에서의 미리보기 렌더링과 캐시 갱신은 별도 확인이 필요합니다. 카카오 SDK나 앱 키는 사용하지 않습니다. 모바일에서는 운영체제 공유 메뉴를, 지원하지 않는 환경에서는 링크 복사를 사용합니다.

## 저장과 전자책

기사 저장은 기존 localStorage 키를 유지해 이전 저장 목록을 보존합니다. 브라우저 간 동기화는 없습니다. 저장소 오류 시 메모리로 대체하며 새로고침 후 유지되지 않을 수 있습니다.

전자책 페이지는 출시 전 구매 의향을 확인하는 페이지입니다. 기존 가제·목차는 기획 미리보기이며 가격·출시일은 미정입니다. 결제·예약·이메일 수집은 연결하지 않았습니다. 관심/취소는 서버의 202 응답을 확인한 뒤 이 기기의 상태를 갱신합니다. 실패 시 성공 메시지를 표시하지 않습니다.

## 분석: 현재 범위와 한계

`POST /api/events`에서 방문, 내부 링크 클릭, 검색 결과 수, 필터, 저장/취소, 공유, 전자책 구매 의향/취소를 검증하고 `nasol_event` JSON으로 Vercel Runtime Logs에 기록합니다. 검색어·연락처·자체 이용자 식별자를 기록하지 않고 DNT를 따릅니다. Vercel 자체 요청 로그에는 플랫폼의 일반 로그 정책이 적용됩니다.

이 단계는 **로그 보관 기간 내 이벤트 수집**입니다. 데이터베이스나 유료 분석 서비스를 신청하지 않았습니다. 영구 누적 집계, 고유 방문자, 중복 없는 구매 의향 수, 운영자 대시보드는 아직 없습니다. 반복 클릭·데이터 삭제·봇의 영향을 받으므로 시장 수요를 고유 인원으로 해석하면 안 됩니다. 관심 표시는 가격 미확정 상태의 구매 고려 의향이며 결제 전환이 아닙니다.

Vercel의 해당 프로젝트 Logs에서 `nasol_event`를 검색해 JSONL을 내보낸 후:

```sh
npm run report < runtime-logs.jsonl
```

내보낸 기간의 페이지·이벤트별 건수와 관심·취소 클릭 수를 요약합니다. 로그 보관 기간은 계정 설정에 따릅니다. 장기 분석은 승인된 기존 저장소 또는 분석 서비스 연결이 후속 작업입니다.

## 원고 상태

기존 원고를 재사용했고 새 기사를 임의로 추가하지 않았습니다. 각 기사에 미리보기 원고임을 표시합니다. 공개 발언·방송 장면·과학적 주장은 출처와 사실 검토 후 정식 발행해야 합니다. 예시 원고를 검증된 보도로 바꾸어 표기하지 않습니다.
